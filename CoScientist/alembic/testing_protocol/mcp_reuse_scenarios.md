# Ручная проверка переиспользования MCP-серверов Alembic

15 сентября 2026 г., ветка `alembic-server-reuse`. Веб-интерфейс `python -m CoScientist web`, модель qwen3-235b-a22b-2507 через OpenRouter, HITL отключён, S3 на локальном MinIO (бакет `agent-vault`). Каждый сценарий в новом чате.

## Сценарии в чате

1. **synspace, сервер остановлен.** `build_mcp_server` нашёл сборку, поднял сервер из образа и дождался ответа MCP, `chemical_space` вернул 10 аналогов. ✅
   ```
   Используй репозиторий https://github.com/whitead/synspace. Посчитай химическое пространство для аспирина CC(=O)Oc1ccccc1C(=O)O (steps=[1,1], nblocks=5, num_samples=10). Верни адрес MCP-сервера и таблицу аналогов.
   ```
2. **synspace, сервер работает.** Тот же запрос: сборка взята без пересборки, инструмент вызван по настоящему имени из поля `tools`. ✅
3. **Остановка кнопкой Stop.** Сервер, остановленный на вкладке сборок, поднимается сам при следующем запросе из п. 1: и из памяти процесса (`check_mcp_build`), и после перезапуска web. ✅
4. **Mordred, явная просьба о сервере из репозитория.** Оркестратор выбрал каталожный `smiles2prop`. Этот исход ожидался, детерминированное правило выбора решили не вводить. ✅
   ```
   Нужно посчитать молекулярные дескрипторы Mordred для кофеина CN1C=NC2=C1C(=O)N(C(=O)N2C)C. Код есть в репозитории https://github.com/mordred-descriptor/mordred: получи по нему MCP-сервер без полной пересборки и вызови расчёт дескрипторов. Верни адрес сервера и число дескрипторов.
   ```
5. **Дескрипторы без репозитория.** McpBuilderAgent не вызывается, используется `smiles2prop`. ✅
   ```
   Посчитай молекулярные дескрипторы для кофеина CN1C=NC2=C1C(=O)N(C(=O)N2C)C. Верни число дескрипторов и несколько ключевых значений.
   ```
6. **Mordred через McpBuilderAgent, большой ответ.** `calculate_descriptors` вернул сокращённый ответ (1371 символ вместо 49 407) со ссылкой `result_s3`. ExperimentAgent достал значения через `read_result`: MW 194,08, SLogP −1,03, TopoPSA 61,82, 1613 дескрипторов. Прошло со второго запуска: в первом модель выбрала `smiles2prop`. ✅
   ```
   Через McpBuilderAgent получи MCP-сервер по репозиторию https://github.com/mordred-descriptor/mordred без полной пересборки (force_rebuild=false), затем вызови на этом сервере расчёт молекулярных дескрипторов Mordred для кофеина CN1C=NC2=C1C(=O)N(C(=O)N2C)C. Верни адрес сервера, названия инструментов сервера, число дескрипторов и значения MW, SLogP и TopoPSA.
   ```
7. **Несуществующий репозиторий.** Сразу ошибка «repository is not reachable», записи сборки нет. ✅
   ```
   Построй MCP-сервер из репозитория https://github.com/ur-whitelab/cf-mol и верни его адрес.
   ```
8. **S3 на входе и выходе, biopython остановлен.** Сервер поднялся за 11 с, `seqio_convert` скачал `rosemary.pro` из MinIO и записал `out_manual.fasta` под ключом сессии. Выходной файл сверен с входным: запись и последовательность (473 символа) совпадают. ✅
   ```
   Используй репозиторий https://github.com/biopython/biopython. Получи MCP-сервер без полной пересборки и вызови инструмент seqio_convert с аргументами in_file="s3://agent-vault/ephemeral/u1/s1/in/rosemary.pro", in_format="fasta", out_file="out_manual.fasta", out_format="fasta". Верни адрес сервера и поле out_file_s3.
   ```
9. **Изоляция сессий.** К исполнителю подключён только каталожный сервер, ни один из четырёх серверов alembic других чатов не попал (строка `DynamicMCPToolset: servers` в `logs/app.log`, уровень DEBUG). ✅
   ```
   С помощью доступных инструментов посчитай молекулярную массу и logP аспирина CC(=O)Oc1ccccc1C(=O)O.
   ```

## Вкладка сборок

10. **Сервер, запущенный вне сборщика** (mordred из `start_chain.py`). Появляется в списке после перезапуска web без участия агента, с пометкой «From image». Артефакты скопированы из образа, есть история и карточки инструментов. ✅
11. **Образ без тега.** Тег `alembic-tool:mordred` занят новой сборкой, у старого сервера работают Start, Stop и Delete. ✅
12. **Отладочный вызов** при остановленном сервере идёт в собственном образе сборки, даже когда тег репозитория уже у новой сборки. ✅
13. **Форма Call** подставляет аргументы из Invocation examples, если записанных вызовов нет. ✅

## Пересоздание при смене S3

14. **Смена бакета** (`S3__BUCKET_NAME` подменён в отдельном процессе). Start удалил остановленный контейнер `mordred-babc36` и поднял новый на том же порту 27969 с новым бакетом. MCP ответил через 1 с, в журнале сборки строка «S3 settings changed». ✅
15. **Возврат к `.env`.** Контейнер снова пересоздан на 27969 с `agent-vault`. Первый прогон нашёл гонку: вкладка сборок принимала новый контейнер за чужой. После исправления повтор с открытой вкладкой (57 проходов обнаружения) лишних записей не дал. ✅

## Известные ограничения

- Выбор между похожими инструментами у модели нестабилен (сценарии 4 и 6).
- Итоговый ответ может показывать presigned-ссылку без `s3_key`, через час она перестаёт открываться.
- Правило маршрутизации к McpBuilderAgent временное, до #305 (`REMINDER(#331, PR #305)`).
