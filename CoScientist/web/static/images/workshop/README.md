# Research workshop artwork

`research-desk.png` was generated with the built-in image_gen tool from the
user-selected `scratchpad/blueprint_concepts/01-workshop.png` visual reference.
It contains only the desk and peripheral scientific supplies. Agent cards,
connections, settings and descriptions are rendered by the application.

Generation prompt:

> Preserve the photographic warm pale oak research desk, soft overhead light,
> natural wood grain, peripheral compass, ruler, dark scientific notebook,
> pencils and small plant. Remove the entire blueprint sheet, all graph nodes,
> graph connections, UI, menus, labels, text and paper clipboards. Replace the
> removed area with uninterrupted oak desktop in the same overhead perspective.
> Wide 3:2 background; central 85% width and 88% height empty wood. Props confined
> to the outer corners: navy notebook lower left, brass compass and triangle
> ruler lower right, cropped plant top left. No center props, blue paper, lines,
> tiles, diagram, text, UI or hands. Finished background for a website, warm
> tactile scientific workshop.

`paper-grain.svg` is a small procedural texture. It contains no text or UI.

## Ceramic node materials

`ceramic-circle.png`, `ceramic-rect.png`, and `ceramic-hexagon.png` were
generated individually with the built-in `image_gen` tool. The original RGBA
files are preserved, including transparent backgrounds. Text, role icons,
selection outlines, brass terminals, and connections are separate live SVG.

Shared prompt:

> Use case: product-mockup. Asset: transparent PNG texture for an interactive
> architecture graph node. Generate ONE isolated matte ivory ceramic game token
> viewed exactly from directly overhead, orthographic. Warm soft light from upper
> left. Cream subtly speckled flat empty front surface, polished rounded bevel
> catching light, visibly thick dark warm beige side rim extending slightly
> downwards, realistic contact shadow cast towards lower right. No letters,
> symbols, logos, brass connectors, props, border or background; genuine
> transparent alpha outside the object. Fill the image tightly with token, leave
> 3 percent margin for shadow. Match a vintage research workbench on blue drafting
> paper.

Shape variants appended to the prompt:

- Circle: perfect circle; square canvas.
- Rectangle: wide rounded rectangle, width to height ratio 2.4:1; landscape canvas.
- Hexagon: point at left and right, horizontal flat top and bottom, width to height
  ratio 1.2:1; square canvas.
